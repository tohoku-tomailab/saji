# 0002 パラメータの型に range と json を足す

- 日付: 2026-09-23

## 背景
HANDOFF はパラメータを int / float / str / bool / 選択肢に限っていた。kaiseki-tool には軸範囲
（`--xlim "526,538"`）や、見た目の辞書（生成物ごとの色、ピークの表示名など）がある。

## 決定（人間の承認済み: フェーズ0の報告 §3）
- `range`: `[下限, 上限]`（片側 None 可）。CLI は `LO,HI`、Web は数値欄2つ。
- `json`: フォームで表しにくい見た目の設定の逃げ道。**例外扱い**で、1ツールに数個まで。
  CLI は JSON 文字列か `@ファイル名`、Web はテキストエリア。
- ピーク表のような「データ」は、パラメータではなく入力ファイル（FileInput）にする。
- 全パラメータは `--params run.json`（manifest.json もそのまま可）で一括指定できる。

## 却下した案
- kaiseki-tool の `--config`（多段の JSON で全引数を指定）をそのまま持ち込む: パラメータの定義が
  二か所に分かれ、Web のフォームを生成できない。
