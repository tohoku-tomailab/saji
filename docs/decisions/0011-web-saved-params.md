# 0011 Web でパラメータ欄の状態を localStorage に保存する

- 日付: 2026-09-27
- 状態: 決定（人間に確認済み）

## 背景

Web 版では、ツールを開くたびにパラメータが既定値に戻る。同じ条件で繰り返し処理することが多いので、
前回の設定が残っていてほしい。

## 決定

- **パラメータ欄の状態を、ツールごとに localStorage に保存する**（キー `saji:params:<ツール名>`、
  値 `{"v": 1, "values": {名前: raw}}`）。欄を変えるたびに保存し、ツールを開くときに戻す。
  実装は `web/app.js` だけ（ツールごとの JS は要らない）。
- 保存するのは送る値ではなく**欄の状態（raw）**: bool → true/false、range → [下限, 上限] の文字列、
  それ以外 → 欄の文字列。空欄は「既定値を使う」意味なので、送る値だけでは区別できないため。
- **既定値と同じ欄は保存しない。** ツールの既定値が後で変わったとき、変えていない欄は新しい既定値に従う。
- 戻すときは1項目ずつ確かめる（無くなった項目、選択肢に無い値、型の合わない値は捨てて既定値にし、
  そのことを表示する）。ツールを更新しても、古い保存値でエラーにならない。
- 既定値から変えた欄には印を付け、詳細設定の見出しに変えた数を出す（前回の値が残っているのに気づかず
  実行するのを防ぐ）。「既定値に戻す」ボタン（直後なら「元に戻す」できる）を置く。
- 「設定を書き出す」は `{"tool", "params"}` の JSON（CLI の `--params` にそのまま渡せる。manifest.json と同じ形）。
  「設定を読み込む」はそれと manifest.json と `{名前: 値}` を受け付ける。CLI と同じく、ファイルに無い項目は既定値。
  別のツールの設定なら、名前の合う項目だけ読み、そのことを表示する。
- localStorage が使えない（プライベートモードなど）ときは保存しないだけで、ほかは今までどおり動く。
- 専用パネル（0005）のツールは対象外（パネルの中身は外枠が知らないため。必要ならパネル側で行う）。
- 確認は `scripts/test_web_form.py`（ヘッドレスブラウザでフォームを操作する）。

## 却下した案

- **入力ファイルも保存する**（IndexedDB ならファイルも入る）: 共用 PC のブラウザに実データが残り続けるため。
  小さく実データでもない参照ピーク JSON だけ「よく使う参照」として保存する案は、別の機能として検討する。
- **実行したときだけ保存する**: 実行する前にページを閉じると、変えた設定が消えるため。
- **送る値（collectParams の結果）を保存する**: 「既定値のまま」と「わざと空にした」を区別できないため。
